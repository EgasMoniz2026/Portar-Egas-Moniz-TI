# Portar-Egas-Moniz-TI
Nota de segurança

A password do Portal TI é apenas uma proteção simples do lado do browser —
não é encriptação real. Impede que alguém abra o ficheiro por acaso ou
espreite por cima do ombro, mas não impede alguém com conhecimentos técnicos
de aceder aos dados guardados através das ferramentas de developer do browser.

Não guardar aqui passwords reais de sistemas — usar um gestor de passwords
dedicado (ex: Bitwarden) para esses casos.
